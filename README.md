# note-remote-mcp

Experimental, unofficial TypeScript remote MCP integration for note.com.

**Status:** Work in progress. Authentication, article editing, cover/body image upload, paid-area boundaries and publishing have **not** been verified end to end with note.com. Do not share account passwords or session cookies.

## Planned capabilities

- Remote MCP endpoint using Streamable HTTP.
- User-guided login in a hosted browser.
- Article drafts with cover and inline images.
- Paid area boundaries and pricing configuration.
- Review-before-publish workflow.

This project is not affiliated with note.com.
